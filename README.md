# SalárioCerto 🧮

Aplicativo web mobile-first para ajudar jovens a organizar suas finanças pessoais.

## 📋 Descrição

O **SalárioCerto** é um aplicativo educativo desenhado para jovens de 17 a 25 anos que estão recebendo seu primeiro salário. O objetivo é desmistificar os descontos do holerite, ensinar organização orçamentária e simular metas financeiras de forma simples e interativa.

## 🎨 Identidade Visual

- **Fundo do App:** Grafite Escuro (`#0F172A`)
- **Cartões/Containers:** Azul Noturno (`#1E293B`)
- **Destaques/Botões:** Verde Menta (`#10B981`)
- **Design:** Mobile-first com tema escuro moderno

## ✨ Funcionalidades

### 1. Simulador de Salário Líquido
Calcula automaticamente os descontos fictícios (INSS 8% e Vale Transporte 6%) e exibe o salário líquido.

### 2. Distribuidor de Orçamento 50/30/20
Divide automaticamente o valor disponível em:
- 50% Necessidades Básicas
- 30% Desejos Pessoais
- 20% Reserva e Futuro

### 3. Simulador de Metas e Conquistas
Calcula o tempo necessário para alcançar um objetivo financeiro com base no valor da meta e quanto pode guardar por mês.

### 4. Quiz de Perfil Financeiro
Diagnóstico interativo com 3 perguntas que identifica o perfil (Gastador, Equilibrado ou Poupador) e fornece dicas personalizadas.

## 🚀 Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Navegue entre as 4 abas usando a barra de navegação inferior
3. Utilize cada funcionalidade conforme sua necessidade

## 📱 Compatibilidade

- Otimizado para smartphones (largura máxima de 430px)
- Responsivo para desktop (container centralizado)
- Funciona em todos os navegadores modernos

## ⚠️ Aviso Legal

Os cálculos utilizam dados fictícios para fins educacionais. Não substitui aconselhamento financeiro profissional.
